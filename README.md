# FlowFix - System Analysis & Design Showcase

This repository contains the front-end implementation of an academic **System Analysis and Design** showcase website. The project analyzes a multi-service digital platform, identifies core architectural and workflow problems, and proposes an **Integrated Incremental Improvement System** named **FlowFix**.

Developed by the **Computer Science and Engineering** department at **Southeast University**, under the guidance of instructor **Md. Tanbeer Jubaer**.

## 🚀 Overview

The project is built as a single-page static application using modern web technologies. It is entirely frontend-based (HTML, CSS, JavaScript) and focuses on presenting complex system design concepts—such as architectures, database schemas, and use case models—using a sleek, interactive, and code-driven UI.

**Key Features of the Showcase:**
- **Problem Analysis:** Outlines 5 core problems in the existing system.
- **Solution Mapping:** Maps each problem to a targeted, incremental improvement.
- **Feasibility Study:** Compares different candidate systems.
- **System Design:** Interactive tabs displaying System Architecture, Use Case Models, and Database ER Designs.
- **UI/UX Mockups:** CSS-based mobile phone frames demonstrating proposed workflow screens (Service Selection, Location Confirmation, Complaint Tracking).

## 🛠️ Technology Stack

- **Vite:** Blazing fast frontend build tool.
- **Tailwind CSS:** Utility-first CSS framework used for layout, typography, and complex glassmorphism styling.
- **Vanilla JavaScript:** Powers intersection observers for scroll animations, smooth scrolling, and tab switching.
- **Lucide Icons:** Clean, consistent SVG icon set.

## 💻 Running Locally

To run this project on your local machine, you will need [Node.js](https://nodejs.org/) installed.

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser to view the site.

3. **Build for production:**
   ```bash
   npm run build
   ```
   This command compiles the final, minified assets into the `dist/` directory, which can be deployed directly to static hosting services like Netlify, Vercel, or GitHub Pages.
